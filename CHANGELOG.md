# Changelog

## 1.0.0

- Initial release of the `explode` package.
- Added the `Explode` widget to create a customizable explosion/shattering effect on child widgets.
- Added `ExplodeController` to support programmatic control of the explosion and reset actions.
- Configurable settings including:
  - `duration`: Custom length of the explosion animation.
  - `particleSize`: Custom size for each explosion particle.
  - `shape`: Circle, rectangle, or triangle particles (`ExplodeParticleShape`).
  - `particleCount`: Target particle count.
  - `explodeArea`: Bounding area for spreading particles.
- Added comprehensive documentation comments for all properties of the `Explode` widget.
